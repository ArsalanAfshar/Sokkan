# Sokkan | سُکّان — Milad Template (میلاد) v2.0

**پک قالب سُکّان — قالب اول: میلاد — لندینگ پریمیوم فارسی برای بازار ایران**

> **Template Pack:** Sokkan (سُکّان) — **Template #1:** Milad (میلاد)

ترکیبِ **فناوریِ آینده + نوستالژیِ گذشته**؛ یک هویت بصری ماتریکسی-وینتیج-رترو فیوچریستیک که با HTML خالص، CSS و جاوااسکریپت وانیلی ساخته شده است — بدون هیچ فریم‌ورک و بدون هیچ وابستگی. حالا با **نمایشگر سه‌بعدی محصول (CSS 3D Monitor)** و **تایپوگرافی اکسترود سه‌بعدی** و **دارک مود بازطراحی شده**.

این نسخه، «میلاد» اولین قالب از پک سُکّان است: تمام اصول طراحی (رنگ، تایپوگرافی، دکمه‌ها، کارت‌ها، انیمیشن‌ها) طوری معماری شده‌اند که نسخه‌های بعدی (سرویس هوش مصنوعی، SaaS، اپلیکیشن، آژانس مارکتینگ و…) با همین سیستم ساخته شوند.

```
Sokkan Pack
├── Milad Template (فعلی) — لندینگ خدمات دیجیتال
├── Future Template 2 — SaaS
├── Future Template 3 — AI
└── ...
```

## ویژگی‌های نسخه ۲٫۰

| قابلیت | توضیح |
|---|---|
| **پک سُکّان + قالب میلاد** | برندینگ صحیح: Sokkan نام پک، Milad نام قالب اول |
| **فارسی اول (RTL)** | محتوای فارسیِ اصیل، نه ترجمه؛ تایپوگرافی وزیرمتن + نسخ، فاصله‌گذاری حرفه‌ای |
| **دو زبانهٔ کامل** | سوییچ فارسی/انگلیسی با تغییر کامل جهت (RTL/LTR) و ذخیرهٔ انتخاب کاربر — فیکس مشکل overflow دکمه زبان |
| **حالت روشن/تاریک — بازطراحی کامل** | کنتراست بهبود یافته، جداسازی کارت‌ها از پس‌زمینه، فرم مشاوره کاملاً خوانا، سایه‌ها و بوردرهای دقیق |
| **تایپوگرافی سه‌بعدی پریمیوم** | جایگزینی outline ساده با extruded/layered effect — ۴ لایه اکستروژن + سافت گلو، ریسپانسیو و سبک |
| **نمایشگر سه‌بعدی محصول (3D Product Showcase)** | کامپوننت مانیتور CSS 3D با محتوای قابل تعویض (تصویر، ویدیو، داشبورد HTML)، انیمیشن float، پارالاکس موس، قابل سفارشی‌سازی با CSS Variables |
| **بک‌گراند جریان داده** | بارش کاراکترهای عددی/باینری روی Canvas — کمرنگ، اسپارس و با بلور ملایم |
| **انیمیشن‌های پریمیوم** | Reveal هنگام اسکرول، شمارنده‌ها، تایپ ترمینال، مارکی، پارالاکس چندلایه، مکعب وایرفریم، شبح شمارهٔ بخش‌ها |
| **واکنش‌گرا — بدون سرریز** | طراحی اختصاصی موبایل، تبلت و دسکتاپ، تست شده برای جلوگیری از horizontal scroll |
| **منوی موبایل پریمیوم** | اسکریم بلورشده + پنل لایه‌لایه با انیمیشن پلکانی لینک‌ها |
| **جایگاه نماد اعتماد** | قاب‌های اختیاری نماد اعتماد الکترونیکی و درگاه‌های پرداخت در فوتر |
| **بدون وابستگی** | HTML5 + CSS3 + Vanilla JS؛ استاتیک، سریع، قابل استقرار روی هر هاستی |
| **دسترس‌پذیر** | ناوبری کیبوردی، ARIA، کنتراست استاندارد، فوکوس قابل مشاهده، احترام به prefers-reduced-motion |

## شروع سریع

این یک وب‌سایت کاملاً استاتیک است؛ کافی است پوشهٔ `milad` را روی هر هاستی آپلود کنید. هیچ مرحلهٔ Build وجود ندارد.

## سفارشی‌سازی نمایشگر سه‌بعدی

در `index.html` بخش `productShowcase` را پیدا کنید:

```html
<div class="product-showcase" style="--rx:-8deg; --ry:18deg; --showcase-scale:1; --float-duration:6.5s;">
  <div class="monitor-screen-content">
    <!-- اینجا محتوای خود را بگذارید -->
    <img src="your-screenshot.jpg" alt="پیش‌نمایش محصول">
  </div>
</div>
```

ویژگی‌های قابل سفارشی‌سازی:
- `--rx`, `--ry`: زاویه چرخش اولیه (مثلاً -8deg, 18deg)
- `--showcase-scale`: مقیاس (0.8 تا 1.2)
- `--float-y`: میزان شناور شدن (8px تا 16px)
- `--float-duration`: سرعت انیمیشن (4s سریع، 8s کند)
- محتوای داخل `.monitor-screen-content`: تصویر، ویدیو، iframe، یا HTML داشبورد

## سفارشی‌سازی رنگ‌ها

همه‌چیز از **متغیرهای CSS** می‌آید. فایل `assets/css/base.css` را باز کنید:

```css
--accent: #ffb443;    /* رنگ برند سُکّان (کهربایی) */
--accent-2: #2dd4a0;  /* سبز ماتریکسی */
--bg: #0a0a0f;        /* پس‌زمینه دارک */
--bg-3: #1e1e2e;      /* کارت‌ها — کنتراست بهبود یافته */
--radius: 16px;
```

## نکات فنی دارک مود

- توکن‌های دارک مود بازطراحی شدند: `bg` #0a0a0f، `bg-2` #12121c، `bg-3` #1e1e2e — فاصله واضح بین سطح‌ها
- فرم درخواست مشاوره: پس‌زمینه `bg-3` روی پنل `ink` #16161f — دیگر محو نمی‌شود
- اینپوت‌ها: پس‌زمینه `bg` روی کارت `bg-3` — تفکیک کامل
- بوردرها و سایه‌ها در دارک مود تقویت شدند

## تاریخچهٔ تغییرات

### ۲٫۰ — «سُکّان — میلاد» (نسخه فعلی)
- **برندینگ:** ENGINE → Sokkan (سُکّان) به عنوان نام پک، Milad به عنوان نام قالب اول حفظ شد
- **فیکس زبان:** دکمه سوییچ زبان از grid به inline-flex تغییر کرد، white-space nowrap، min-width ریسپانسیو، بدون overflow
- **دارک مود:** Audit کامل — بهبود کنتراست bg/bg-2/bg-3، فرم مشاوره، کارت‌ها، اینپوت‌ها، هدر، فوتر
- **تایپوگرافی سه‌بعدی:** outline ساده → extruded layered effect با ۴ لایه + گلو، em-based، بدون overflow
- **3D Showcase:** کامپوننت مانیتور CSS 3D با محتوای قابل تعویض، float animation، mouse parallax، ریسپانسیو
- **هیرو:** بازطراحی به دو ستون (محتوا + نمایشگر) در دسکتاپ، استک در موبایل
- **ساختار پک:** آماده برای قالب‌های آینده، کد تمیز و قابل استفاده مجدد
