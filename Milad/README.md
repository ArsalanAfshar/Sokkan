# میلاد | Milad

قالب ایستای تک‌صفحه‌ای برای معرفی استودیوهای دیجیتال و کسب‌وکارهای خدماتی؛ با هویت بصری ماتریکس × وینتیج، راست‌چین پیش‌فرض، ترجمهٔ انگلیسی، پوستهٔ روشن/تاریک و چیدمان واکنش‌گرا.

> **پیش‌نمایش:** نام، آمار، تعرفه، نظر مشتری، ساعات پاسخ‌گویی، تماس و متن‌های معرفی نمونه‌اند. قبل از انتشار با اطلاعات واقعی و مجاز جایگزین شوند.

## اجرا

از ریشهٔ مخزن سرور محلی را اجرا کنید و `http://localhost:8000/Milad/` را باز کنید:

```bash
python3 -m http.server 8000
```

هیچ وابستگی build یا CDN لازم نیست.

## تغییرات رایج

- متن فارسی در `index.html` و متن انگلیسی در شیء `EN` در `assets/js/main.js` است. برای هر `data-i18n`، متن انگلیسی هم‌کلید را نگه دارید.
- رنگ‌ها و فونت‌ها در `assets/css/base.css`؛ اجزا و بخش‌ها در `components.css` و `sections.css` هستند.
- تصویر دستگاه در `assets/img/screen-preview.svg` است؛ برای محصول واقعی از تصویر دارای مجوز و متن جایگزین دقیق استفاده کنید.
- `legal.html` یک **پیش‌نویس نمونه** است، نه مشاورهٔ حقوقی. جای‌خالی‌ها و شرایط را برای کسب‌وکار و قوانین جاری بازبینی کنید.

## فرم تماس

فرم `#ctaForm` به‌طور پیش‌فرض `data-endpoint=""` دارد؛ با ارسال آن صفحه پیامی نشان می‌دهد که هیچ اطلاعاتی ارسال نشده است. برای استفادهٔ واقعی، endpoint امن و هم‌مبدأ روی HTTPS تعریف کنید؛ کد فعلی JSON زیر را با `POST` می‌فرستد:

```json
{"name":"...","phone":"09...","service":"web","message":"..."}
```

سرور باید ورودی را دوباره اعتبارسنجی، در برابر CSRF و هرزنامه محافظت، نرخ درخواست را محدود و سیاست نگهداری/حذف داده را اجرا کند. فقط پاسخ HTTP موفق باعث نمایش حالت موفقیت می‌شود؛ کلید محرمانه یا درگاه پرداخت در مرورگر قرار ندهید.

## فونت‌ها و آزمون

`assets/fonts/` شامل WOFF2 محلی و مجوزهای SIL OFL مربوط است؛ متن مجوزها در همان پوشه و `../../LICENSES/` است. از ریشهٔ مخزن اجرا کنید:

```bash
python3 scripts/audit_pack.py
```
