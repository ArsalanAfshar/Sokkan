# چیدار | Chidar

پیش‌نمایش فروشگاه اینترنتی دکور و دست‌سازه با چیدمان RTL، فارسی/انگلیسی، فیلتر دسته‌بندی، جست‌وجو، مرتب‌سازی قیمت، سبد خرید مرورگری و پوستهٔ روشن/تاریک.

> **فروشگاه آمادهٔ دریافت سفارش نیست.** قیمت، هزینهٔ ارسال، محصولات، نظرات و زمان‌بندی نمونه‌اند. سبد خرید در مرورگر محاسبه می‌شود؛ پرداخت، سفارش سمت سرور، موجودی و خبرنامه متصل نیستند.

## اجرا

از ریشهٔ مخزن:

```bash
python3 -m http.server 8000
```

قالب در `http://localhost:8000/Chidar/` قابل مشاهده است. وابستگی npm یا CDN لازم نیست.

## محصولات و زبان

- متن‌های دو زبان در `Chidar/index.html` و دیکشنری‌های `FA` و `EN` در `assets/js/main.js` هستند.
- اطلاعات اولیهٔ محصول در کارت‌های `data-product-card` قرار دارد؛ کاتالوگ و قیمت را با دادهٔ واقعی، عکس دارای مجوز و ارز مشخص به‌روزرسانی کنید.
- سبد خرید در `localStorage` مرورگر ذخیره می‌شود و **منبع معتبر سفارش، قیمت یا موجودی نیست**.
- تصویر بزرگ دکور با هوش مصنوعی ساخته شده و SVGهای محصول تصویرسازی نمونه‌اند؛ آن‌ها را عکس واقعی کالا معرفی نکنید. پیش از فروش، تصاویر صحیح و دارای حق استفاده جایگزین و الزامات بازار انتشار بررسی شوند.

## اتصال خبرنامه و پرداخت

تنظیمات اختیاری در `window.CHIDAR_CONFIG` خوانده می‌شوند. می‌توان آن‌ها را در اسکریپتی پیش از `assets/js/main.js` افزود:

```html
<script>
  window.CHIDAR_CONFIG = {
    newsletterEndpoint: '/api/newsletter',
    checkoutEndpoint: '/api/checkout',
    freeShippingThreshold: 3500000,
    shippingFee: 85000
  };
</script>
```

مقادیر ارسال/ارسال رایگان در این مثال صرفاً نمونه‌اند. endpoint فروشگاه باید روی HTTPS و زیر کنترل سرور خودتان باشد. مرورگر هنگام ثبت سفارش فقط شناسهٔ محصول و تعداد را می‌فرستد؛ سرور باید قیمت، موجودی و واحد پول نهایی را از کاتالوگ معتبر دوباره محاسبه کند، سفارش را امن ثبت کند و تراکنش را با درگاه مجاز سمت سرور تأیید کند. پاسخ endpoint پرداخت باید یک `redirectUrl` با HTTPS برای درگاه مورد اعتماد برگرداند (در توسعهٔ محلی، آدرس HTTP هم‌مبدأ پذیرفته می‌شود). فقط پس از اتصال endpoint خبرنامه و اطلاع‌رسانی مناسب، ایمیل مشتری را جمع‌آوری کنید.

`legal.html` صرفاً پیش‌نویس نمونهٔ شرایط و حریم خصوصی است؛ متن ارسال، بازپرداخت، پرداخت، داده و کوکی را با عملیات واقعی فروشگاه تطبیق دهید و بازبینی حقوقی محلی بگیرید. مجوز فونت‌های محلی در `assets/fonts/` و `../LICENSES/` است.

از ریشهٔ مخزن ممیزی را اجرا کنید:

```bash
python3 scripts/audit_pack.py
```
