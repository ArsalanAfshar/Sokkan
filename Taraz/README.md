## 🎯 درباره قالب تراز

قالب تراز یک لندینگ پیج حرفه‌ای و تجاری برای معرفی نرم‌افزارهای حسابداری، مدیریت مالی و پلتفرم‌های SaaS مالی است. این قالب با هویت بصری **مدرن، حرفه‌ای و قابل اعتماد** طراحی شده و تجربه‌ای پریمیوم برای کاربران ایرانی ارائه می‌دهد.

### ویژگی‌های منحصربه‌فرد

- 💼 **طراحی حرفه‌ای مالی** — مناسب برای نرم‌افزارهای حسابداری و مالی
- 📊 **داشبورد تعاملی** — پیش‌نمایش محصول با انیمیشن‌های نرم
- 🎨 **هویت بصری مدرن** — رنگ‌های زمردی و آبی، حس اعتماد و فناوری
- 🌙 **حالت تاریک و روشن** — با کنتراست عالی در هر دو حالت
- 📱 **واکنش‌گرایی کامل** — از موبایل تا دسکتاپ
- 🌐 **دوزبانه** — فارسی (RTL) و انگلیسی (LTR)
- ⚡ **عملکرد بهینه** — بدون وابستگی خارجی
- ♿ **دسترسی‌پذیر** — مطابق با استانداردهای WCAG

## 🎨 سفارشی‌سازی

### ۱. تغییر رنگ‌ها

فایل `assets/css/base.css` را ویرایش کنید:

```css
:root[data-theme="light"] {
  --accent: #10b981;      /* رنگ اصلی (زمردی) */
  --secondary: #3b82f6;   /* رنگ ثانویه (آبی) */
  --warning: #f59e0b;     /* رنگ تأکیدی (طلایی) */
  --bg: #ffffff;          /* رنگ پس‌زمینه */
  --text-primary: #0f172a; /* رنگ متن اصلی */
}
```

### ۲. تغییر محتوای متنی

تمام متون در `index.html` با اتریبیوت `data-i18n` مشخص شده‌اند:

```html
<h1 data-i18n="hero_title_1">عنوان شما</h1>
<p data-i18n="hero_subtitle">توضیحات شما</p>
```

ترجمه‌های انگلیسی در `assets/js/main.js` در شیء `translations.en` قرار دارند.

### ۳. جایگزینی پیش‌نمایش داشبورد

فایل `assets/img/dashboard-preview.svg` را با تصویر خود جایگزین کنید:

```html
<img src="assets/img/your-screenshot.png" 
     alt="پیش‌نمایش محصول شما" 
     class="showcase-image">
```

**نکات:**
- فرمت‌های پیشنهادی: PNG, JPG, SVG, WebP
- اندازه پیشنهادی: حداقل 800×600 پیکسل
- نسبت تصویر: 4:3 یا 16:9

### ۴. تغییر پلن‌های قیمت‌گذاری

در `index.html`، بخش `pricing-grid` را ویرایش کنید:

```html
<div class="pricing-card">
  <div class="pricing-name">نام پلن</div>
  <div class="pricing-amount">قیمت</div>
  <ul class="pricing-features">
    <li>ویژگی ۱</li>
    <li>ویژگی ۲</li>
  </ul>
</div>
```

### ۵. افزودن زبان جدید

در `assets/js/main.js`، دیکشنری جدید اضافه کنید:

```javascript
const translations = {
  fa: { /* فارسی */ },
  en: { /* انگلیسی */ },
  ar: { /* عربی */ }  // زبان جدید
};
```

## 🌐 دوزبانگی

قالب تراز از دو زبان پشتیبانی می‌کند:

1. **فارسی** (پیش‌فرض) — RTL
2. **انگلیسی** — LTR

### تغییر زبان

```javascript
// در main.js
function toggleLanguage() {
  currentLang = currentLang === 'fa' ? 'en' : 'fa';
  updateLanguage();
}
```

### افزودن زبان جدید

1. دیکشنری جدید در `translations` اضافه کنید
2. تابع `t(key)` را برای زبان جدید تنظیم کنید
3. دکمه تغییر زبان را به‌روز کنید
