# Engine | انجین — v1.2 «میلاد»

**قالب لندینگ پریمیوم خدمات دیجیتال برای بازار ایران**

ترکیبِ **فناوریِ آینده + نوستالژیِ گذشته**؛ یک هویت بصری ماتریکسی-وینتیج که با HTML خالص، CSS و جاوااسکریپت وانیلی ساخته شده است — بدون هیچ فریم‌ورک و بدون هیچ وابستگی.

این نسخه، «بنیان» پک آیندهٔ قالب‌های لندینگ است: تمام اصول طراحی (رنگ، تایپوگرافی، دکمه‌ها، کارت‌ها، انیمیشن‌ها) طوری معماری شده‌اند که نسخه‌های بعدی (سرویس هوش مصنوعی، SaaS، اپلیکیشن، آژانس مارکتینگ و…) با همین سیستم ساخته شوند.

## ویژگی‌ها

| قابلیت | توضیح |
|---|---|
| **فارسی اول (RTL)** | محتوای فارسیِ اصیل، نه ترجمه؛ تایپوگرافی وزیرمتن + نسخ |
| **دو زبانهٔ کامل** | سوییچ فارسی/انگلیسی با تغییر کامل جهت (RTL/LTR) و ذخیرهٔ انتخاب کاربر |
| **حالت روشن/تاریک** | دو تمِ واقعاً طراحی‌شده (نه اینورت رنگ) با کنتراست استاندارد WCAG |
| **بک‌گراند جریان داده** | بارش کاراکترهای عددی/باینری روی Canvas — کمرنگ، اسپارس و با بلور ملایم؛ فضا می‌سازد، مزاحم محتوا نیست |
| **انیمیشن‌های پریمیوم** | Reveal هنگام اسکرول، شمارنده‌ها، تایپ ترمینال، مارکی، شاخص‌ها، پارالاکس چندلایه، مکعب وایرفریم سه‌بعدی، شبح شمارهٔ بخش‌ها |
| **واکنش‌گرا** | طراحی اختصاصی موبایل، تبلت و دسکتاپ بدون سرریز افقی |
| **منوی موبایل پریمیوم** | اسکریم بلورشده + پنل لایه‌لایه با انیمیشن پلکانی لینک‌ها و پشتیبانی کامل تم روشن/تاریک |
| **جایگاه نماد اعتماد** | قاب‌های اختیاری نماد اعتماد الکترونیکی و درگاه‌های پرداخت در فوتر — آمادهٔ درج لوگو |
| **بدون وابستگی** | HTML5 + CSS3 + Vanilla JS؛ استاتیک، سریع، قابل استقرار روی هر هاستی |
| **دسترس‌پذیر** | ناوبری کیبوردی، ARIA، کنتراست استاندارد، فوکوس قابل مشاهده، احترام به prefers-reduced-motion |
| **سئو-آماده** | متا تگ‌ها، Open Graph، دادهٔ ساخت‌یافته (JSON-LD) |

## ساختار پروژه

```
engine/
├── index.html                 ← کل صفحه (ساختار و محتوای فارسی)
├── assets/
│   ├── css/
│   │   ├── fonts.css          ← تعریف فونت‌های محلی (تولیدشده)
│   │   ├── base.css           ← توکن‌های طراحی: رنگ، فونت، دکمه، تایپوگرافی، انیمیشن
│   │   ├── components.css     ← هدر، ناوبری، لودر، مارکی، فرم، فوتر، توست
│   │   └── sections.css       ← استایل بخش‌های صفحه (هیرو، خدمات، تعرفه‌ها و…)
│   ├── js/
│   │   └── main.js            ← منطق صفحه + دیکشنری انگلیسی (i18n)
│   └── fonts/                 ← فونت‌های واریبل woff2 (وزیرمتن، نسخ عربی، JetBrains Mono)
└── docs/screenshots/          ← پیش‌نمایش‌ها
```

## شروع سریع

این یک وب‌سایت کاملاً استاتیک است؛ کافی است پوشهٔ `engine` را روی هر هاستی (یا GitHub Pages، Netlify، Vercel، CDN ایرانی) آپلود کنید. هیچ مرحلهٔ Build وجود ندارد.

## سفارشی‌سازی

### ۱. رنگ‌ها و هویت (بدون دست زدن به بقیه)
همه‌چیز از **متغیرهای CSS** می‌آید. فایل `assets/css/base.css` را باز کنید؛ در بلوک `:root` و دو تم `dark`/`light` مقدارها را عوض کنید:

```css
--accent: #ffb443;    /* رنگ برند (کهربایی) */
--accent-2: #2dd4a0;  /* سبز ماتریکسی */
--accent-3: #ff6b4a;  /* قرمز توماتویی */
--bg: #0b0b0e;        /* پس‌زمینه */
--radius: 16px;       /* گوشه‌ها */
```

### ۲. محتوای فارسی
متن‌ها مستقیماً در `index.html` هستند (اتریبیوت `data-i18n` کلید هر متن است).

### ۳. نسخهٔ انگلیسی
دیکشنری انگلیسی در `assets/js/main.js` و در آبجکت `EN` است. هر کلید `data-i18n` یک معادل انگلیسی دارد؛ کافی است متن‌ها را ویرایش کنید.

### ۴. فونت
فونت‌ها به‌صورت محلی (آفلاین) در `assets/fonts` قرار دارند و در `fonts.css` تعریف شده‌اند. برای تغییر فونت: فایل woff2 جدید را جایگزین و `fonts.css` را به‌روز کنید. (فونت‌های فعلی تحت مجوز OFL هستند.)

### ۵. افزودن / حذف بخش
هر بخش یک `<section class="section" id="...">` مستقل است. برای حذف، کل بلاک را بردارید و لینک منو و دیکشنری را پاک کنید. برای افزودن، از ساختار بخش‌های موجود کپی بگیرید — کلاس‌های `eyebrow`، `sec-title`، `card` و `reveal` خودکار استایل می‌گیرند.

### ۶. تصاویر
این قالب عمداً بدون عکس طراحی شده (کاور پروژه‌ها با CSS ساخته می‌شود) تا سبک و بدون وابستگی بماند. برای افزودن عکس، برچسب `<img>` را داخل `.wm-art` یا `.work-media` بگذارید؛ نسبت تصویر از قبل تنظیم است.

### ۷. نماد اعتماد و درگاه پرداخت (فوتر)
در پایین فوتر یک نوار اختیاری با قاب‌های خط‌چین برای «نماد اعتماد الکترونیکی» و «لوگوهای درگاه پرداخت» آماده است. کافی است تصویر را داخل هر قاب بگذارید:

```html
<span class="trust-slot">
  <img src="assets/img/enamad.png" alt="نماد اعتماد الکترونیکی">
</span>
```

اگر این نوار را نمی‌خواهید، بلاک `footer-trust` را از `index.html` حذف کنید؛ بقیهٔ فوتر دست‌نخورده می‌ماند.

### ۸. اتصال فرم
فرم «مشاورهٔ رایگان» نمایشی است و به هیچ سرویسی متصل نیست. هندلر آن در انتهای `main.js` (بخش `FORM & TOAST`) آمادهٔ اتصال به API، ایمیل یا تلگرام است.

## نکات فنی

- **تم پیش‌فرض** از `prefers-color-scheme` سیستم می‌آید و انتخاب کاربر در `localStorage` ذخیره می‌شود (بدون فلش رنگ هنگام لود).
- **اعداد فارسی** در شمارنده‌ها و تاریخ‌ها به‌صورت خودکار مدیریت می‌شوند.
- **بک‌گراند ماتریکسی** فقط روی هیرو رسم می‌شود، با `requestAnimationFrame` و توقف خودکار در حالت reduce-motion.
- مرورگرهای هدف: آخرین دو نسخهٔ Chrome، Safari، Firefox و Edge (به‌دلیل استفاده از Logical Properties، `color-mix` و `svh`).

## اعتبار محتوا

همهٔ برندها، اعداد، قیمت‌ها، آدرس و شماره‌تماس‌ها در این نسخه **نمایشی و فرضی** هستند و باید با اطلاعات واقعی مشتری جایگزین شوند.

## نقشهٔ راه پک

- `engine-saas` — لندینگ محصول SaaS
- `engine-ai` — سرویس هوش مصنوعی
- `engine-app` — اپلیکیشن موبایل
- `engine-agency` — آژانس دیجیتال مارکتینگ

همه بر پایهٔ همین سیستم طراحی و کد ساخته خواهند شد.

## تاریخچهٔ تغییرات

### ۱٫۲ — «پرداخت نهایی» (آخرین به‌روزرسانی)
- جریان دادهٔ هیرو آرام‌تر و عمیق‌تر شد: کاراکترها کاملاً باینری/عددی/نمادین (با شکاف‌های عمدی در جریان)، بلور میدان قوی‌تر، کادربندی وینیت برای جداسازی محتوا
- متن توخالی (Outline) در حالت تاریک هالهٔ ظریف کهربایی گرفت — خوانایی بیشتر بدون تغییر هویت
- تیلت سه‌بعدی ظریف کارت‌ها و آیکون‌های خدمات (فقط ماوس، حداکثر ۱٫۵ درجه، transform-only)
- میکرواینترکشن‌ها: جاروی نور روی دکمه‌های اصلی، خط پیشرفت اسکرول بالای صفحه، رینگ آواتار نظرات، راهنمای هاور قاب‌های نماد اعتماد
- متن ویژگی‌ها واقعی‌تر شد (SLA مکتوب، پشتیبانی آخر هفته، بکاپ خودکار)

### ۱٫۱ — «پرداخت نهایی»
- بازسازی کنتراست حالت تاریک: متن‌های فرعی، برچسب‌ها و اعداد به سطح خوانایی WCAG AA رسیدند (بدون روشن‌کردن کلی فضا)
- بک‌گراند ماتریکسی → «جریان داده»: کاراکترهای عددی/باینری/نمادین (بدون حروف ژاپنی)، تراکم کمتر، بلور ملایم میدان و دو هالهٔ نور عمق‌ساز
- اصلاح رندر متن توخالی (Outline): ضخامت استروک نسبی به اندازهٔ فونت، فاصلهٔ حروف مثبت و padding داخلی — بدون تماس حروف در فارسی و انگلیسی
- منوی موبایل بازسازی شد: اسکریم تارکننده + پنل مات لایه‌لایه + انیمیشن پلکانی لینک‌ها + پشتیبانی safe-area و تم روشن/تاریک
- انیمیشن‌های جدید: پارالاکس چندلایه (فقط transform)، مکعب وایرفریم سه‌بعدی شناور، تراشه‌های دادهٔ مونو، شبح شمارهٔ بخش‌ها، میکرواینترکشن‌های هاور
- محتوای نمایشی واقعی‌تر: مثال‌های ملموس از پروژه‌ها (فین‌تک، فروشگاه، برندینگ) در خدمات، نظرات و فرآیند
- نوار اختیاری «نماد اعتماد الکترونیکی + درگاه‌های پرداخت» به فوتر اضافه شد
