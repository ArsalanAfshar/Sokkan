# Sokkan | سکّان — مجموعه قالب پریمیوم

## قالب میلاد (Milad Template)

**قالب لندینگ پریمیوم خدمات دیجیتال برای بازار ایران**

بخشی از **مجموعه قالب‌های سکّان** — قالب‌های حرفه‌ای HTML برای کسب‌وکارهای ایرانی.

ترکیبِ **فناوریِ آینده + نوستالژیِ گذشته**؛ یک هویت بصری ماتریکسی-وینتیج که با HTML خالص، CSS و جاوااسکریپت وانیلی ساخته شده است — بدون هیچ فریم‌ورک و بدون هیچ وابستگی.

## ویژگی‌ها

| قابلیت | توضیح |
|---|---|
| **فارسی اول (RTL)** | محتوای فارسیِ اصیل، نه ترجمه؛ تایپوگرافی وزیرمتن + نسخ |
| **دو زبانهٔ کامل** | سوییچ فارسی/انگلیسی با تغییر کامل جهت (RTL/LTR) و ذخیرهٔ انتخاب کاربر |
| **حالت روشن/تاریک** | دو تمِ واقعاً طراحی‌شده با کنتراست استاندارد WCAG |
| **بک‌گراند جریان داده** | بارش کاراکترهای عددی/باینری روی Canvas — کمرنگ، اسپارس و با بلور ملایم |
| **دستگاه سه‌بعدی** | کامپوننت نمایش محصول با انیمیشن شناور و تعامل ماوس — قابل استفاده در پروژه‌های خریدار |
| **تایپوگرافی پریمیوم** | افکت متنی سه‌بعدی/لایه‌ای برای عناوین — حرفه‌ای و رترو-فیوچریستیک |
| **انیمیشن‌های پریمیوم** | Reveal هنگام اسکرول، شمارنده‌ها، تایپ ترمینال، مارکی، شاخص‌ها، پارالاکس چندلایه |
| **واکنش‌گرا** | طراحی اختصاصی موبایل، تبلت و دسکتاپ بدون سرریز افقی |
| **منوی موبایل پریمیوم** | اسکریم بلورشده + پنل لایه‌لایه با انیمیشن پلکانی لینک‌ها |
| **جایگاه نماد اعتماد** | قاب‌های اختیاری نماد اعتماد الکترونیکی و درگاه‌های پرداخت در فوتر |
| **بدون وابستگی** | HTML5 + CSS3 + Vanilla JS؛ استاتیک، سریع، قابل استقرار روی هر هاستی |
| **دسترس‌پذیر** | ناوبری کیبوردی، ARIA، کنتراست استاندارد، فوکوس قابل مشاهده |
| **سئو-آماده** | متا تگ‌ها، Open Graph، دادهٔ ساخت‌یافته (JSON-LD) |

## ساختار پروژه

```
milad/ (engine/)
├── index.html                 ← کل صفحه (ساختار و محتوای فارسی)
├── assets/
│   ├── css/
│   │   ├── fonts.css          ← تعریف فونت‌های محلی
│   │   ├── base.css           ← توکن‌های طراحی: رنگ، فونت، دکمه، تایپوگرافی، انیمیشن
│   │   ├── components.css     ← هدر، ناوبری، لودر، مارکی، فرم، فوتر، توست
│   │   └── sections.css       ← استایل بخش‌های صفحه + دستگاه سه‌بعدی
│   ├── js/
│   │   └── main.js            ← منطق صفحه + دیکشنری انگلیسی (i18n) + تعامل سه‌بعدی
│   └── fonts/                 ← فونت‌های واریبل woff2 (وزیرمتن، نسخ عربی، JetBrains Mono)
└── docs/screenshots/          ← پیش‌نمایش‌ها
```

## شروع سریع

این یک وب‌سایت کاملاً استاتیک است؛ کافی است پوشه را روی هر هاستی آپلود کنید. هیچ مرحلهٔ Build وجود ندارد.

## سفارشی‌سازی

### ۱. رنگ‌ها و هویت
همه‌چیز از **متغیرهای CSS** در `assets/css/base.css` می‌آید.

### ۲. دستگاه سه‌بعدی (Hero)
کامپوننت `.hero-device` در Hero یک نمایشگر محصول سه‌بعدی است. محتوای صفحه دستگاه (`.screen-content`) قابل جایگزینی است:
- تصویر اسکرین‌شات
- ویدیو
- محتوای HTML
- داشبورد یا رابط اپلیکیشن

متغیرهای قابل تنظیم:
- `deviceFloat` — سرعت انیمیشن شناور
- `rotateY/rotateX` — میزان چرخش
- تعامل ماوس از `main.js` قابل تنظیم است

### ۳. محتوای فارسی
متن‌ها مستقیماً در `index.html` هستند (اتریبیوت `data-i18n` کلید هر متن است).

### ۴. نسخهٔ انگلیسی
دیکشنری انگلیسی در `assets/js/main.js` و در آبجکت `EN` است.

### ۵. اتصال فرم
فرم «مشاورهٔ رایگان» نمایشی است. هندلر آن در `main.js` آمادهٔ اتصال به API است.

## نکات فنی

- **تم پیش‌فرض** از `prefers-color-scheme` سیستم می‌آید و انتخاب کاربر در `localStorage` ذخیره می‌شود.
- **اعداد فارسی** در شمارنده‌ها و تاریخ‌ها به‌صورت خودکار مدیریت می‌شوند.
- مرورگرهای هدف: آخرین دو نسخهٔ Chrome، Safari، Firefox و Edge.
