# Sokkan | سُکّان — Template Pack

**پک قالب‌های پریمیوم فارسی — طراحی شده برای بازار ایران**

> **Pack Name:** Sokkan (سُکّان) — **First Template:** Milad (میلاد)

Sokkan یک پک قالب HTML تجاری است که برای کسب‌وکارهای دیجیتال ایرانی طراحی شده است. هویت بصری آن ترکیبی از **Matrix × Vintage × Retro-Futuristic** است — مدرن، نوستالژیک، و حرفه‌ای.

این ریپازیتوری شامل قالب‌های زیر است:

```
Sokkan/
├── milad/ — قالب میلاد (فعلی) — لندینگ خدمات دیجیتال
│   ├── index.html
│   ├── assets/css/
│   ├── assets/js/
│   └── ...
├── (آینده) saas/ — لندینگ محصول SaaS
├── (آینده) ai/ — سرویس هوش مصنوعی
├── (آینده) app/ — اپلیکیشن موبایل
└── ...
```

## قالب میلاد — ویژگی‌ها

- **RTL-first، فارسی اصیل** — نه ترجمه
- **سوییچ زبان فارسی/انگلیسی** — بدون overflow، کاملاً ریسپانسیو
- **دارک مود بازطراحی شده** — کنتراست و سلسله مراتب بصری واضح
- **تایپوگرافی سه‌بعدی اکسترود** — جایگزین outline ساده
- **نمایشگر سه‌بعدی محصول (CSS 3D Monitor)** — کامپوننت قابل استفاده مجدد برای نمایش وب‌سایت، داشبورد، اپلیکیشن
- **بدون وابستگی** — HTML5 + CSS3 + Vanilla JS
- **کاملاً ریسپانسیو** — بدون horizontal scroll
- **ساختار قابل توسعه** — آماده برای قالب‌های آینده پک

## شروع سریع

```bash
# قالب میلاد
cd milad
# یک سرور ساده اجرا کنید
python -m http.server 8000
# یا فایل index.html را مستقیم باز کنید
```

## برندینگ

- **Sokkan / سُکّان** — نام پک قالب (برند اصلی)
- **Milad / میلاد** — نام قالب اول

در تمام قالب‌ها:
- از Sokkan برای اشاره به پک استفاده کنید
- از Milad برای اشاره به قالب اول استفاده کنید

مثال صحیح:
```
Sokkan Template Pack
Milad Template
قالب میلاد از پک سُکّان
```

## توسعه قالب‌های آینده

تمام قالب‌های آینده باید از همین سیستم طراحی استفاده کنند:

- توکن‌های طراحی در `milad/assets/css/base.css`
- کامپوننت‌های مشترک در `components.css` و `sections.css`
- کامپوننت 3D Showcase قابل استفاده مجدد است
- از CSS Variables برای سفارشی‌سازی استفاده کنید
